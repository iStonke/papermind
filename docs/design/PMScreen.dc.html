Einkframe – Mac ↔ Pi Sync & Betrieb
Diese Datei ist eine Kurz- und Langzeit-Gedächtnisstütze für sicheren Git-Abgleich zwischen Mac (Entwicklung) und Raspberry Pi (Produktion).
Grundprinzip
Mac = Quelle der Wahrheit – hier wird entwickelt und gepusht
Pi zieht ausschließlich von origin/main
Laufzeitdaten werden niemals automatisch gelöscht
Auf dem Mac
git status
git add .
git commit -m "beschreibung"
git push
Alles, was der Pi sehen soll, muss gepusht sein.
